## Project Description  
**Language Learning App – Save and Review Vocabulary Words**  
This application enables users to save and review vocabulary words in an interactive and structured manner. It includes a test mode where users can input translations, receive immediate feedback, and track their performance with a detailed score (correct vs. incorrect responses).  
The interface supports multiple languages and provides options to reveal answers, navigate through words, and promote effective vocabulary retention.
